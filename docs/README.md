# Image Merge CGI

Простое CGI-приложение на C++, предназначенное для наложения изображений, генерации номеров (например, водяных знаков) и управления файлами через строку запроса.

## 🚀 Запуск

Приложение работает как **CGI-скрипт** в веб-сервере (Apache, Nginx и др.).

Пример вызова:
```
http://yoursite.com/cgi-bin/merge?layer=base.png|0|0|0|100|0|100|0&out=result.png
```

Для отладки (с флагом `_DEBUG`) можно запустить напрямую:
```bash
./merge
```
⚠️ Убедитесь, что переменная окружения QUERY_STRING установлена, если запускаете без _DEBUG.


## 🖼 Операции
1. **Добавление слоя (layer)**

Добавляет изображение в стек с параметрами.

Формат:
```
layer=имя_файла|x|y|z|фильтр|цвет|масштаб|угол
```

Параметры:

x, y — позиция.
z — порядок слоя.
фильтр — прозрачность (0–100).
цвет — цветовой фильтр (0 = нет).
масштаб — масштаб в процентах.
угол — поворот в градусах.

2. **Сохранение результата (out)**

Задаёт имя выходного файла.

Формат:
```
out=output.png
```

Поддерживаемые форматы: .png, .jpg, .jpeg.


 **🔐 Имя файла проверяется на безопасность.**


3. **Генерация номера (number, type, source)**

Генерирует изображение с текстом.

Пример:
```
number=AB123&type=1&source=mask.png&out=out.png
```

4. **Копирование и удаление**

copy=src.png|dst.png
delete=file.png
🛡 Безопасность
Все пути проверяются.
Только разрешённые расширения.
Ограничение по символам в имени файла.
